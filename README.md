# JavaScript Laserpointer

A small JavaScript experiment exploring Xbox controller input using the browser's gamepad API

## Controls

| Action | Keyboard | Controller | 
|--------|----------|------------|
| Move   | WASD/Arrow keys| Left stick |
| Squeak | Spacebar | A button |

## Built with
- HTML
- CSS
- JavaScript
